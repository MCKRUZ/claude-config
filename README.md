## Restore on a new machine — one liner

```powershell
irm https://raw.githubusercontent.com/MCKRUZ/claude-config/main/bootstrap/quick-install.ps1 | iex
```

Or the long way:

```powershell
git clone https://github.com/MCKRUZ/claude-config
cd claude-config
pwsh ./bootstrap/install.ps1
```

Bootstrap will:

1. Verify APM is installed (install with `irm https://aka.ms/apm-windows | iex` on Windows)
2. Prompt for the secrets listed in `settings/secrets.example.env`
3. Render `settings/settings.template.json` into `~/.claude/settings.json`
4. Copy `rules/` and `hooks/` into `~/.claude/` with paths rewritten for the current user
5. Run `apm install --target claude` at user scope
6. For each project in `projects/index.json`, `cd` into it and run `apm install`
7. Run `apm audit` to verify reproducibility
