# README Snippet Templates

```markdown
## Screenshot
![Screenshot](./output/screenshot.png)
```

## Demo GIF
```markdown
## Demo
![Demo](./output/demo.gif)
```

## Multiple screenshots
```markdown
## Screenshots

| Feature | Preview |
|---------|---------|
```
