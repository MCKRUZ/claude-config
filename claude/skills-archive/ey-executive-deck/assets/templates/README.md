# EY Templates

Official EY Global Widescreen Presentation Templates v2.1

## Files

- `ey-dark.pptx` — Dark theme with spectrum backgrounds (77 slides)
- `ey-light.potx` — Light theme with white backgrounds (67 slides)

## Usage

**Slides 1-4 are guidance slides** — Remove before distributing presentations.

### Template Selection

| Use Dark When | Use Light When |
|---------------|----------------|
| External client presentations | Internal working sessions |
| High-impact executive pitches | Document-heavy appendices |
| Section dividers and title slides | Data-heavy analysis slides |
| Evening/conference room presentations | Printed materials |

### Working with Templates

1. **Copy slides from template** — Don't modify the template file directly
2. **Preserve the footer** — Maintain EY logo, slide numbers, and date
3. **Follow color rules** — See `brand/ey-brand.md` for guidelines
4. **Use solid backgrounds for content** — Reserve spectrum for titles/dividers
